# 02 · 核心工作逻辑

> **版本说明**：v2（2026-09-24）—— 按第二次会议决议修订。关键变更：队列改 **FIFO**（原得分公式废除）、新增**上传冷却**、碎片改**图片分享**、域**全员退出自动消失**（AI DJ 兜底降级为远景）、歌品值体系**取消**。详见会议记录 2026-09-24。

## 域的生命周期（五步闭环）

```
1. 创建域
   ≥3 首歌 + 场景命名 + 公开/私密 + 标签过滤（禁止含/仅允许含）+ 可选番茄钟
        │
        ▼
2. 场景分发（仅公开域）
   把域推给「正在做同件事」的用户（首页只推此刻活跃的域）
        │
        ▼
3. 同频收听 + 上传歌曲
   全员同步 · 不可暂停/切歌 · 按上传顺序 FIFO · 10 分钟冷却
        │
        ▼
4. 图片分享
   上传歌曲时可选附图，图片与歌曲关联 → (场景, 图, 歌) 三元组数据
        │
        ▼
5. 消散与沉淀
   全员退出 → 域自动消失；消失前生成域歌单供成员收藏【暂定假设】
```

### 第 1 步：创建域
- 门槛：≥3 首歌 + 一个场景名即可开域
- 场景名自由文本 + 系统归一化为场景标签（如"考研自习""自习室""图书馆刷题"归为同一类），避免流量过度分散
- **可见性**（决议 D2）：公开域（可推荐/搜索/分类展示）或私密域（邀请链接 / 密码进入）
- **标签过滤**（决议 D5）：五类标签（语言/年代/风格/场景/情绪），域主二选一模式——「禁止含」或「仅允许含」
- 可选：番茄钟时段配置（见下）

### 第 2 步：场景分发
- 首页信息流 = 推荐主题域列表（决议 D9：玻璃卡片 = 主题名 + 封面 + 在线人数 + 当前播放曲名/歌手）
- **只推活跃的公开域**（有播放流、近 N 分钟有上传/图片行为），私密域不参与分发
- 上滑页面时顶部出现横向分类标签栏（全部/音乐/学习/健身/旅行/日系/电子/城市/深夜…）

### 第 3 步：同频收听与上传队列

**播放规则**（决议 D3，2026-09-24 定稿）：
- 同一域内所有用户同步播放；**用户不能自行暂停、恢复或切歌**
- **歌曲按上传顺序（FIFO）播放**；当前播放歌曲突出显示，其他人等待自然结束
- 当前播放项在歌单列表中同步高亮

> ⚠️ v1 的"队列得分公式"（点赞×2 + 域主加成×3 − 刷屏惩罚×1.5）已**废除**——点赞不再影响播放顺序，仅作互动信号（喂养审美反馈）。

**上传冷却**（决议 D4）：
- 单用户在单个域内 **10 分钟只能上传 1 首歌**
- 达到限制时「上传歌曲」按钮置灰，按钮上/旁显示冷却倒计时（如"10:00 后可上传"），倒计时结束恢复

**上传准入校验**：
```
上传 → ① 冷却检查（10 分钟内已传 → 拒绝，返回剩余冷却秒数）
     → ② 域级标签过滤（黑名单命中 → 拒绝 / 白名单模式不含 → 拒绝）
     → ③ 番茄钟时段白名单（不符合 → 入预存队列，允许时段自动转正）
     → ④ 入队尾（FIFO）
```

### 时段分段（番茄钟）与预存队列

> 2026-09-23 会议决议 D3，与域级过滤**叠加生效**

域支持番茄钟式时段分段，分段绑定曲风标签白名单：

- 例：自习域 = 40 分钟专注段（仅允许「舒缓」标签）+ 10–20 分钟休息段（允许「流行」等标签）
- **预存队列**：不符合当前时段白名单的歌曲入预存队列，到允许时段自动转正——"上传动作自由，播放时机守规则"
- 抽象统一：域级过滤管"这个域永远不要什么/只要什么"，时段白名单管"这个时段只要什么"

### 队列空与域消散

- v1 的"AI DJ 兜底补歌"**降级为远景待验证**（2026-09-24 会议未提及，且与"全员退出自动消失"逻辑冲突）
- MVP 行为：队列播完则域静默等待新上传；**全员退出后域自动消失**（决议 D2）

### 第 4 步：图片分享（原"碎片"机制修订，决议 D6）

- 用户**上传歌曲时可选同时上传一张图片**，图片与歌曲关联，标记上传用户与对应歌曲
- 主界面动态区只展示 **1–2 张**图片卡片（避免信息过载），可横滑查看近期图片
- 点击进入动态区：展示**半小时内**上传的图片流（时间倒序）
- 用户**可撤回**自己上传的图片
- 每条图片分享 = (场景, 图片, 关联歌曲) 三元组结构化数据——数据飞轮源头（见 03 文档）
  - ⚠️ 与 v1 差异：v1 为"发碎片自动绑定当前播放"；v2 绑定逻辑改为"上传歌曲时绑定"，数据语义更精确

### 第 5 步：消散与沉淀

- **域自动消失**：全员退出后域关闭，进入历史
- **歌单沉淀【暂定假设】**：域消失前将播放过的曲目生成静态歌单，供成员收藏——待下次会议确认（2026-09-24 未决问题）
- **数据反哺**：三元组数据进入配乐推荐模型（见 03 文档）

## 审美反馈机制

> 2026-09-24 决议 D7（v1 决议 D2 的克制版）

- **微光提示**：你上传的歌在播放时被收藏，页面边缘出现短暂柔光；不用强震动/夸张动画
- **互动**：歌曲点赞、收藏、emoji 轻互动（爱心/大笑/点赞）、关注上传者
- **边界**：不支持评论区；私聊复用宿主 App
- **去游戏化**：不做积分/等级/勋章——v1「歌品值」体系取消，不再有点赞率资产化设计
- 行为事件仍埋点统计（收藏/关注/emoji），作为推荐与配乐模型的反馈信号

## 关键风险的预案

| 风险 | 预案 |
|------|------|
| 空房间（长尾域死寂） | 首页只推活跃公开域；场景标签归一化聚流；域无人自动消失（自然出清）；AI DJ 留作远景 |
| 上传刷屏 | 10 分钟冷却（决议 D4）+ 标签过滤 |
| 播放顺序争议 | FIFO 天然公平，无排序争议；域主无播放特权（人人平等） |
| 私密域滥用 | 私密域不进推荐/搜索；密码与邀请链接可控分发（错误次数限制待确认） |
| UGC 内容安全 | 图片审核管线（先审后发）；撤回机制；举报入口（域内页"更多"按钮） |

另需平台侧配套：实时共听版权在宿主音乐 App 授权框架内（"一起听"模式已验证）。

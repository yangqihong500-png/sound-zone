# 04 · MVP 与路线图

> **版本说明**：v3（2026-09-25）—— 在 v2 的 6 页面、FIFO、冷却和去歌品值决策上，将产品形态调整为**独立 App / H5 Demo**；uni-app 继续保留多端构建能力，曲库改为可替换 Provider。

## MVP 范围

先验证最核心的假设：**"场景命名的实时共听"是否成立**。

MVP 页面（2026-09-24 决议 D9 定稿的 6 个页面/弹窗）：
1. **首页**：推荐域列表（玻璃卡片）+ 极简搜索 + 上滑分类标签 + 悬浮「创建域」按钮
2. **域内页**：当前播放区 + 动态分享区（1-2 张）+ 歌单列表（FIFO）+ 底部上传操作栏（冷却倒计时）
3. **创建域页**：主题输入 + 五类标签 + 过滤双模式 + 私密设置（密码/邀请链接）
4. **动态详情页**：半小时图片流 + 撤回 + emoji 互动
5. **上传歌曲弹窗**：曲库搜索 + 冷却倒计时
6. **上传图片弹窗**：图片选择 + 绑定本人本次上传的歌曲（具体队列条目）

MVP 机制：**全员同步播放（不可切歌）+ FIFO 队列 + 10 分钟冷却 + 标签过滤（禁/仅）+ 公开/私密域 + 图片分享与撤回 + 收藏微光提示**。

刻意不做：评论区、私聊界面、游戏化（积分/等级/歌品值）、AI DJ、番茄钟（MVP 后第一批）、品牌联名。

冷启动：**2 个官方域**（自习 + 健身）官方运营保密度。

## 验证指标

| 指标 | 含义 | 健康信号 |
|------|------|----------|
| 同频收听时长 | 域的陪伴价值 | 人均单日 ≥ 30 分钟 |
| 上传参与率 | 互动意愿（受冷却约束） | 日活跃听众中 ≥ 15% 有上传行为 |
| 图片分享率 | UGC 供给 + 数据飞轮源头 | 上传行为中 ≥ 30% 附带图片 |
| 收藏率 | 审美认可信号 | 日播放曲目中 ≥ 10% 被收藏 |
| 次日留存 | 场景匹配质量 | ≥ 35% |

## 阶段路线图

### 阶段一：MVP 验证（0–2 个月）
- 6 页面 + 核心机制（同步播放/FIFO/冷却/过滤/私密域/图片分享/微光）
- 视觉规范落地（日式简约 + 莫兰迪主题色 + 玻璃拟态）
- 2 个官方域，验证上述五个指标

### 阶段二：增长与完善（2–4 个月）
- **明星同款域**冷启动：官方整理明星在采访中分享的歌建域，自带流量
- 番茄钟时段分段（2026-09-23 会议 D3）+ 预存队列
- 关注体系完善（关注列表、关注者上传提醒）
- 域歌单沉淀（待确认的暂定假设，若通过则在此落地）

### 阶段三：KOL 域主生态（4–6 个月）
- 邀请博主/KOL 创建域——对博主而言是展示审美的机会
- 域分享卡片 + 邀请链接裂变
- AI DJ 补歌（远景机制，届时评估与"自动消失"的关系）

### 阶段四：数据飞轮变现（6 个月+）
- 配乐推荐模型成熟后对内接入（智能配图建议）、对外探索短视频配乐 API
- **品牌联名域试点**（2026-09-23 会议远景）：咖啡店/健身房门店域，定位准入 + 门店音响联动

## 冷启动策略总览

```
官方运营域（保密度）
    → 明星同款域（带流量）
        → KOL 域主（带生态）
            → 全民建域（长尾供给，公开+私密）
```

## 风险清单

| 风险 | 等级 | 应对 |
|------|------|------|
| 空房间（长尾域死寂） | 高 | 只推活跃公开域、场景归一化、域无人自动消失（自然出清）、AI DJ 远景 |
| 音乐版权（实时共听） | 高 | Demo 使用 Audius 官方开放播放和留存凭证的授权小曲库；公开运营前复核具体授权范围 |
| 外部曲库依赖 | 中 | `MusicProvider` 隔离 Audius；保留 `LOCAL_LICENSED` 小曲库作为演示兜底 |
| 曲风标签质量不达标 | 中 | 过滤/番茄钟都依赖标签准确性：音频+元数据多标签分类，人工抽检校准，灰度上线 |
| UGC 内容管理 | 中 | Demo 图片即时展示；保留文件校验、撤回 + 举报入口 |
| 视觉规范落地工作量 | 中 | 玻璃拟态在小程序端性能有限，准备降级方案（半透明+软阴影近似） |
| 明星/KOL 合作不及预期 | 低 | 官方域可独立成立，合作为放大器而非前提 |

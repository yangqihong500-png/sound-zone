# 04 · MVP 与路线图

## MVP 范围

先验证最核心的假设：**"场景命名的实时共听"是否成立**。

MVP 只做三件事：
1. **2 个官方域**（自习 + 健身）——官方运营保证活跃密度，规避冷启动空房间
2. **点歌台**（曲库点歌 + 点赞排序队列）
3. **碎片墙**（照片/文案 + 自动挂当下配乐）

刻意不做：用户自建域、歌品值、AI DJ（MVP 期用人工运营歌单兜底）。

## 验证指标

| 指标 | 含义 | 健康信号 |
|------|------|----------|
| 同频收听时长 | 域的陪伴价值 | 人均单日 ≥ 30 分钟 |
| 点歌参与率 | 互动意愿 | 日活跃听众中 ≥ 15% 有点歌行为 |
| 碎片发布率 | UGC 供给 + 数据飞轮源头 | 日活跃听众中 ≥ 5% 发碎片 |
| 点歌点赞率 | 歌品机制有效性 | 平均每条点歌 ≥ 2 赞 |

## 阶段路线图

### 阶段一：官方域验证（0–2 个月）
- 2 个官方域 + 点歌 + 碎片墙
- 验证上述四个指标

### 阶段二：明星同款域冷启动（2–4 个月）
- 官方收集男团女团成员、明星在采访/综艺中分享过的歌，整理成同类型域（如「IU 的睡前歌单」）
- 明星同款自带流量和话题，是第一次增长杠杆
- 开放用户自建域（限量邀请制，控制供给质量）
- 上线歌品值体系

### 阶段三：KOL 域主生态（4–6 个月）
- 邀请博主/KOL 创建域——对博主而言这是展示审美的机会，有自发动机
- 域歌单沉淀 + 站外分享，形成拉新闭环
- AI DJ 上线，长尾域激活

### 阶段四：数据飞轮变现（6 个月+）
- 配乐推荐模型成熟后，对内全面接入（智能配乐、AI DJ 升级）
- 对外探索短视频平台配乐 API 合作

## 冷启动策略总览

```
官方运营域（保密度）
    → 明星同款域（带流量）
        → KOL 域主（带生态）
            → 全民建域（长尾供给）
```

## 风险清单

| 风险 | 等级 | 应对 |
|------|------|------|
| 空房间（长尾域死寂） | 高 | AI DJ 兜底、只推活跃域、场景标签归一化、异步点歌 |
| 音乐版权（实时共听） | 高 | 依托 TME 曲库授权体系（"一起听"模式已验证） |
| UGC 内容安全 | 中 | 图片/文案审核管线，先审后发（碎片墙非实时性可接受） |
| 点歌队列体验恶化 | 中 | 队列得分公式 + 域主管理权 |
| 明星/KOL 合作不及预期 | 低 | 官方域可独立成立，合作为放大器而非前提 |

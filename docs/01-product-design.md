# 01 · 产品设计

## 产品定位

**同频 SoundZone**：基于场景命名的实时共听社区。

不是歌单工具，而是**场景电台**——歌单是"结果"，域是"过程"。

## 痛点分析

### 痛点 1：普通人的审美表达没有流量
用户想 show 自己的歌品和审美，但在现有音乐平台分享歌单，除非是大 V，否则几乎无人看到。审美表达欲被压抑。

### 痛点 2：同审美、同爱好的社交缺位
现有音乐社交（评论区的、一起听）要么太泛（歌曲评论区人群混杂），要么太重（一起听需要先有好友关系）。"正在做同件事的人"这个最自然的连接维度没有被产品化。

## 核心洞察

**「域名 = 正在做的事」是整个产品最值钱的设计。**

传统歌单按"曲风/情绪"分类，要求用户先懂音乐、会描述心情；而「考研自习」「日本 solo trip」「拼豆」「夜跑」这种场景命名：

- 用户不需要任何音乐知识就能找到归属，分发门槛降为零
- 场景天然带时间和状态语义（深夜、通勤、专注），比"伤感""治愈"更精准
- 场景无限细分，任何正在做的事都可以成为一个域，长尾供给充足

## 核心概念：域（Zone）

一个域由三部分组成：

```
┌─────────────────────────────────────┐
│  域 · 考研自习室（场景容器）          │
│  ┌─────────────────────────────────┐│
│  │ 同频电台 · 实时播放流            ││
│  │ 所有人同步听同一首歌             ││
│  └─────────────────────────────────┘│
│  ┌──────────────┐ ┌────────────────┐│
│  │ 点歌台        │ │ 碎片墙          ││
│  │ 曲库点歌      │ │ 照片/文案       ││
│  │ 点赞加权排序  │ │ 自动挂当下配乐  ││
│  └──────────────┘ └────────────────┘│
└─────────────────────────────────────┘
   域主：建域 + 初始歌单 + 管理
   同频者：收听 + 点歌 + 发碎片
```

- **同频电台**：实时播放流，所有在域成员同步收听，营造"共处感"
- **点歌台**：任何成员可从曲库点歌进入队列，队列按社区反馈排序
- **碎片墙**：成员发布此刻的照片/文案，自动绑定发布时域内正在播放的歌

## 角色设计

| 角色 | 权利 | 动机 |
|------|------|------|
| 域主 Host | 创建域、设置初始歌单（≥3 首）、**曲风标签黑名单**、队列管理权、域信息编辑 | 表达审美、聚集同好、获得域主等级与流量激励 |
| 同频者 | 收听、点歌、点赞队列中的歌、发布碎片 | 陪伴感、发现好歌、低门槛参与 |

## 曲风标签体系：域的风格治理

> 决议来源：2026-09-23 会议记录「域的风格由创建者说了算」

**问题**：域的风格若靠域主口头约束无法执行，若由系统统一规定又失去个性。

**方案**：系统为曲库歌曲统一打上多维曲风标签（如：流行、抖音热曲、情歌、舒缓……），域主创建域时从标签列表勾选「本域禁止」的标签——带这些标签的歌无法在该域被点歌。

- 例：《跳楼机》带「流行 / 抖音热曲 / 情歌」标签；某域勾选禁止「抖音热曲」「情歌」后，该歌在此域不可点
- 标签的另一面是白名单：番茄钟分段等场景按"当前时段只允许某类标签"运转（见 02 文档）
- 风格治理 = 域主定调性（黑名单）+ 系统保底线（标签准确性）

## 审美反馈：让"被认可"看得见

> 决议来源：2026-09-23 会议记录

- **实时特效**：轮到你点的歌播放时，其他听众的红心/收藏会在你的屏幕上即时触发特效——满足感发生在当下
- **域后复盘推送**：域结束后向参与者推送统计："你推荐的歌让 X 人第一次听到""被 Y 人收藏"，特效次数纳入统计

这是"show 歌品"痛点的直接产品化，且行为事件天然可统计，反哺歌品值体系。

## 远景方向：品牌联名域

与线下品牌（咖啡店、连锁健身房等）联名：品牌总部或单门店创建自己的域，用户**定位到店**才能进入，门店音响播放的音乐由域内点歌决定——顾客真正参与门店氛围共建。把"域"从线上场景延伸到线下商业空间，是 B 端合作与生态化的抓手（详见 03、04 文档）。

## 视觉风格方向（待调研）

参考苹果式极简 + 设计感，研究磨砂玻璃（毛玻璃）质感；每个域可拥有不同视觉风格（皮肤化）。——2026-09-23 会议提出，待专项调研。

## 与竞品的差异

| 产品 | 模式 | 我们的差异 |
|------|------|-----------|
| QQ音乐/网易云歌单 | 静态、异步 | 域是实时流动的"过程"，且按场景而非曲风组织 |
| 一起听 | 1v1 / 小圈子，需先有好友 | 域是开放的陌生人同频，场景即入口 |
| 语音直播/电台 | 主播单向输出 | 域内人人可点歌，审美由社区共建 |
| 豆瓣小组/贴吧 | 异步图文 | 域以实时音频流为粘合剂，图文是副产品 |

## 命名建议

产品名「同频」，核心单位叫「域」（Zone）。Slogan 候选：

- "此刻，和你做同一件事的人，在听同一首歌"
- "正在做的事，就是最好的歌单分类"

## 交付方向

比赛仍以 H5 Demo、演示视频和封面图为目标。本轮交付代码、迁移与业务验收；不包含公开部署、视频制作、封面图或外部服务采购。

## 固定技术栈

| 层 | 当前实现 |
|---|---|
| 客户端 | uni-app Vue3 + JavaScript + SCSS |
| 后端 | Spring Boot 3.3 + Java 17 + Spring Data JPA |
| 数据库 | MySQL 8；版本化增量 SQL，启动 validate |
| 实时连接 | Spring WebSocket，REST 快照与重连兜底 |
| 播放状态 | MySQL 持久化 + 服务端时钟 + 域行锁 |
| 图片 | 本地持久目录、受保护读取；Demo 上传后即时展示 |
| 音源 | MusicProvider；Audius 官方流或 `LOCAL_LICENSED` 授权 HTTPS 音源，宿主桥仅为可选扩展 |

不引入新框架，不重写分层。后续算法实验可独立开展，不改变业务服务技术栈。

## 最小闭环

1. 游客或账号登录 → 输入域名、选择必选场景并选择恰好三首不同的有效曲目即可创建；公开／私密和标签过滤属于可选高级设置。
2. 服务端按 FIFO 推进，广播状态版本；客户端对齐开始时间和时钟偏差。
3. 成员上传歌曲，五分钟冷却；当前曲和待播队列均为空时自动解除冷却；为自己的本次上传可选附图。
4. 图片上传成功后立即进入三十分钟动态流；支持撤回、单选 emoji、关注与收藏。
5. 收藏仅向上传者发送微光；全员退出或失联后域结束。
6. 记录必要业务事件；仅用户授权的有效图片可进入训练导出，撤回可追溯到导出批次。
7. 创建域时可选共享番茄钟；服务端统一推进专注／休息阶段，当前歌曲自然播完，阶段标签不匹配的待播歌曲暂存并在允许阶段自动恢复。

## 优先级与后续阶段

| 优先级 | 内容 | 本轮处理 |
|---|---|---|
| P0 | 身份／私密准入、FIFO／冷却、心跳／消散、图片归属／即时展示、前后端契约 | 完成业务闭环及迁移 |
| P1 | 真实互动、个人内容、活跃筛选、基础指标、授权导出、共享番茄钟、文档纠偏 | 按确认建议落地 |
| P2 | AI DJ、域歌单沉淀、推荐及配乐模型 | 保留后续规划，不擅自上线 |

番茄钟提供经典 25/5 与深度 40/10 两种固定预设；阶段配乐标签属于可选高级配置。普通域不创建时段，行为保持不变。取消歌品值、积分、评论和手动切歌；不扩建域后战报。

## 外部接入与验收边界

用户确认没有可接入宿主，产品按独立 App / H5 Demo 实施。游客会话默认开启，并可原地升级为用户名密码账号；Audius 提供真实搜索和播放，本地授权曲库提供可控兜底。音源缺失仍明确显示不可播放，图片上传成功后即时展示，不再提供审核服务。密码登录在本地可验证，生产 Compose 默认关闭；完成 HTTPS 后通过 `SOUNDZONE_PASSWORD_AUTH_ENABLED=true` 开放。公开运营仍需补充密码找回、限流与合规条款。

保持小程序构建能力；H5 / App 的域名、网络白名单和发布配置按目标平台设置。比赛日期、外部服务价格和公开发布安排未作为本轮实施前提，也不沿用旧文档中的估价或资质判断。

# 03 · 数据飞轮

> **版本说明**：v2（2026-09-24）—— 按第二次会议修订：碎片改为「图片分享」（上传歌曲时绑定图片，三元组语义更精确）；歌品值体系取消，商业化条目相应调整。

## 一句话

**图片分享 = 用户主动标注的（场景, 图片, 音乐）三元组**——这正是多模态配乐模型最稀缺的数据，也是竞品难以复制的壁垒。

## 飞轮四步

```
① 收集
   用户上传歌曲时可选附图 → 每条分享 = 场景标签 + 图片 + 关联歌曲
   （图片对应的是用户自己上传的歌，语义比"当前播放"更精确）
        │
        ▼
② 建模
   CLIP 式双塔：图片 encoder ↔ 音乐 encoder，对齐到同一向量空间
   学习「什么样的画面/场景配什么样的歌」
        │
        ▼
③ 应用（两个出口）
   对内：域分发推荐优化 · 上传歌曲时的智能配图建议
   对外：短视频/图文平台「内容 → 配乐」推荐 API（B 端收入）
        │
        ▼
④ 反哺
   配乐越准 → 域体验越好 → 用户越愿分享 → 回到 ①，模型持续变强
```

## 为什么这个数据是稀缺的

- 现有配乐推荐多依赖人工规则或粗粒度标签（"欢快""治愈"），缺乏**真实场景语义**
- 市面上的图文-音乐配对数据基本是爬取的、噪声大；而域内分享是用户在真实使用时刻的主动选择，标注质量高
- 场景标签（考研自习、夜跑、solo trip）提供了音乐消费研究中极缺的"情境上下文"维度
- v2 绑定逻辑（图片 ↔ 用户自己上传的歌）比 v1（图片 ↔ 当时恰好播放的歌）因果更强、噪声更低

## 模型方案（数据科学视角）

### 双塔匹配架构
- **内容塔**：图片 → 视觉 encoder（如 ViT）
- **音乐塔**：音频特征（梅尔频谱 → audio encoder）+ 五类标签（语言/年代/风格/场景/情绪）
- **训练目标**：对比学习（InfoNCE），让同一条分享的图与歌在向量空间靠近
- **冷启动**：先用公开数据集（图文-音乐对）预训练，域内数据做领域微调

### 其他算法模块
| 模块 | 方法 |
|------|------|
| 域分发推荐 | 双塔召回（用户画像 × 域标签）+ 活跃度加权排序（仅公开域） |
| 上传队列 | 规则：FIFO + 10 分钟冷却 + 标签过滤（见 02 文档）——**v2 起无需排序模型** |
| 场景归一化 | 场景名文本聚类 + 同义合并 |
| 曲风标签打标 | 音频特征 + 元数据多标签分类（五类标签），人工抽检校准（支撑过滤/番茄钟白名单） |
| 反馈信号 | 收藏/点赞/关注/emoji 事件 → 推荐系统显式正反馈（v2 起不再计算歌品值） |

## 商业化出口

1. **对内**：提升留存与时长（智能配图建议、推荐优化让域体验滚雪球）
2. **对外 B 端**：为短视频平台提供「图片/视频 → 配乐」推荐 API
3. **会员增值**：高音质域、专属域皮肤（莫兰迪主题）
4. **KOL 域合作**：品牌/博主定制域，流量分成
5. **品牌联名域**（远景，2026-09-23 会议提出）：与线下品牌（咖啡店、连锁健身房等）联名——品牌门店建域、用户定位到店才能进入、门店音响由域内上传驱动。域从线上延伸到线下商业空间，打开 B 端生态化收入

## 数据合规

- 分享图片用于模型训练需用户协议授权（发布时勾选"同意用于推荐优化"）
- 用户行为埋点脱敏处理，场景标签聚合后使用
- 图片撤回后同步从训练集剔除（与撤回机制联动）

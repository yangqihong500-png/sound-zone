# 03 · 数据飞轮

## 一句话

**碎片 = 用户主动标注的（场景, 图/文, 音乐）三元组**——这正是多模态配乐模型最稀缺的数据，也是竞品难以复制的壁垒。

## 飞轮四步

```
① 收集
   每条碎片 = 场景标签 + 图片/文案 + 配乐（用户主动标注，带真实场景语义）
        │
        ▼
② 建模
   CLIP 式双塔：图/文 encoder ↔ 音乐 encoder，对齐到同一向量空间
   学习「什么样的画面/心情/场景配什么样的歌」
        │
        ▼
③ 应用（两个出口）
   对内：AI DJ 补歌 · 发碎片时智能配乐推荐
   对外：短视频/图文平台「内容 → 配乐」推荐 API（B 端收入）
        │
        ▼
④ 反哺
   配乐越准 → 域体验越好 → 用户越愿发碎片 → 回到 ①，模型持续变强
```

## 为什么这个数据是稀缺的

- 现有配乐推荐多依赖人工规则或粗粒度标签（"欢快""治愈"），缺乏**真实场景语义**
- 市面上的图文-音乐配对数据基本是爬取的、噪声大；而域内碎片是用户在真实使用时刻的主动选择，标注质量高
- 场景标签（考研自习、夜跑、solo trip）提供了音乐消费研究中极缺的"情境上下文"维度

## 模型方案（数据科学视角）

### 双塔匹配架构
- **内容塔**：图片 → 视觉 encoder（如 ViT）；文案 → 文本 encoder
- **音乐塔**：音频特征（梅尔频谱 → audio encoder）+ 元数据标签
- **训练目标**：对比学习（InfoNCE），让同一条碎片的内容与配乐在向量空间靠近
- **冷启动**：先用公开数据集（图文-音乐对）预训练，域内数据做领域微调

### 其他算法模块
| 模块 | 方法 |
|------|------|
| 域分发推荐 | 双塔召回（用户画像 × 域标签）+ 活跃度加权排序 |
| 点歌队列 | 规则公式（见 02 文档），后期可学排队效用模型 |
| AI DJ 补歌 | 域内碎片配乐偏好的序列推荐（下一首预测） |
| 场景归一化 | 场景名文本聚类 + 同义合并 |

## 商业化出口

1. **对内**：提升留存与时长（AI DJ、智能配乐让域体验滚雪球）
2. **对外 B 端**：为短视频平台提供「图片/视频 → 配乐」推荐 API
3. **会员增值**：高音质域、专属域皮肤、歌品值认证徽章
4. **KOL 域合作**：品牌/博主定制域，流量分成

## 数据合规

- 碎片图片/文案用于模型训练需用户协议授权（发布时勾选"同意用于推荐优化"）
- 用户行为埋点脱敏处理，场景标签聚合后使用

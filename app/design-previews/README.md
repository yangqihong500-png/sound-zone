# SoundZone 视觉方向预览

这些图仅用于比较视觉方向，尚未应用到 uni-app 页面。图中的曲目、封面和统计数据均为示意，不代表后端数据。

- [V1：蓝白撞色](soundzone-blue-white-v1.png)：白底为主，钴蓝实体操作按钮配白字，信息区和悬浮栏保留白色毛玻璃。
- [V1 品牌蓝对比：B / C / H](soundzone-v1-blue-comparison-b-c-h.png)：保持同一套 V1 页面和玻璃质感，只比较深钴蓝 `#1D4ED8`、经典科技蓝 `#0066CC` 与柔和钢蓝 `#3B6EA8`。
- [V2 首稿（未采纳）](soundzone-blue-stained-glass-v2.png)：方格和叠层效果过重，仅保留作对比记录。
- [V2 修订稿：单片蓝色玻璃](soundzone-single-pane-blue-glass-v2-revised.png)：保持 V1 双屏布局；重点按钮采用单片钴蓝有色玻璃的轻微透光、自然色泽变化和极细边缘，底栏及设置区维持浅色磨砂玻璃。

V2 修订稿已去掉方格、拼块、多层叠加和厚描边，整体保持简洁。

V1 已确定为后续方向，品牌蓝选择 H 柔和钢蓝 `#3B6EA8`。该配色已应用到前端视觉层：实体操作、选中态与中央创建入口使用 H 蓝；封面保持原色，图片信息层使用中性玻璃，避免与品牌蓝混色。V2 两稿保留作对比记录。
